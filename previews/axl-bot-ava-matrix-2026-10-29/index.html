Why call it a LAM?

Both LLM- and LAM-based agents can call APIs. Scaled Cognition describes APT as specialised around action choices, policy constraints and outcomes.

What remains outside the model

Pricing, eligibility, permissions and transaction truth belong to the tools and business systems. Specialisation is not a guarantee.

The LAM chooses what to try next. The quote service and system of record determine what actually happened.

A real requirement

The spec is the bridge—not the paperwork.

One human-readable behaviour becomes build guidance and observable evidence.

01 · Authored requirement

When a customer asks for a comparable second quote, reuse confirmed trip and traveller details, ask only for the requested differences, create a separate quote, and compare only fields returned by the quote service. Do not accept or purchase either option.

02 · Proposed tool pre-instruction

Keep quote A and its confirmed trip context. For quote B, copy unchanged fields, apply only the requested difference, call createTravelQuote again, retain the new quote ID, then compare only fields returned by both records.

03 · Planned test

Given quote A exists, the customer asks for winter sports cover. Expect quote B with the same trip and travellers plus the requested extra; show both returned prices and extras; make no acceptTravelQuote call.

Human outcome: authored source. Build guidance: proposed. Evidence: planned, not run.

Change one rule

A useful spec survives a change of mind.

When the comparison request changes, we can see what else must change—and which tests to rerun.

Starting rule: The second option changes one extra while all confirmed trip details remain the same.

New requirement

The customer may ask for another comparison criterion—cover level, destination or extras—and the agent must confirm only the fields that genuinely changed.

Implementation impact

Retain a comparison set containing quote IDs and explicit differences. Preserve unchanged context, label each option and never overwrite a previous quote.

Test to rerun

Start with quote A. Ask for quote B with winter sports, then quote C with a different cover level. Expect three retained quote IDs, unchanged trip fields where appropriate, and a comparison based only on returned data.
