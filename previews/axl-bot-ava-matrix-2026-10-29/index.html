LAM versus LLM

LLM or LAM: why do actions matter?

Both approaches can use the same APIs. The important difference is what their training emphasises.

PrincipleGeneral-purpose LLMAction-specialist LAM
Primary objectiveBroad language understanding, generation and reasoning.Action choices across tasks, tools and policy constraints.
What is it trained to get right?Broad language and reasoning tasks, with tool use available through agent frameworks.Choosing appropriate actions in policy-constrained customer workflows, using action-focused training.
Reliability controlsNeeds orchestration, authorisation, validation and tests.Targets better action reliability; needs the same controls and tests.

APT-2 explained

An action model, not just a conversational model

Scaled Cognition designed the APT family for action-oriented customer tasks. APT-2 is the newer Genesys AVA model.

MODEL FAMILY

APT = Agentic Pretrained Transformer

Scaled Cognition describes action-level objectives, synthetic task/policy simulations and self-play in the APT-1 foundations. Genesys identifies APT-2 as the newer LAM.

  1. CONTEXT

    Understand the request

    The customer changes a trip destination. What is known, missing or outdated?

  2. APT-2

    Choose an allowed action

    Select the permitted quote tool, or ask for a missing field; do not assume acceptance.

  3. GENESYS TOOL

    Execute and enforce

    The configured Data Action reaches the synthetic quote service; backend rules still apply.

  4. RESULT

    Ground the response

    Use the returned quote state and price. If the customer says “maybe”, do not accept.

What APT-2 adds

Genesys reports improvements to reasoning quality, latency, usable context, longer tasks and multilingual performance.

What it does not promise

No zero-error guarantee. Test model changes and real tool failures before relying on production behaviour.

The model decides what to request; the tool and system of record establish what actually happened.
