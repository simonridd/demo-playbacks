The operating challenge

The next call may be for a different business

With around 5,000 clients, receptionists need the right greeting, information and next step for each business they answer for.

  1. Identify the client

    The number dialled can identify the client and route the call.

  2. Bring up that client’s instructions

    The receiving queue and its configuration determine which guidance is available.

  3. Handle the request

    The receptionist decides what to say, what to capture and who should follow up.

A recognised need can trigger a chosen response.

An intent is the recognised need. A rule links a trigger to assistance, such as a checklist. Rules can also use conversation start, transfer or end.

  1. 01Customer words

    I need to change my delivery address.

  2. 02Recognised intent

    Address change

  3. 03Configured rule

    Display the address-change checklist

Find the guidance that answers the question.

A rule can show a chosen article. Fallback search can find relevant content when no rule applies. Article lists, answer highlights and generated answers depend on the knowledge settings. Generated answers require a content-search-enabled knowledge base.

  1. 01Customer question

    Can I change the address after dispatch?

  2. 02Address-change guidance

    Before dispatch: check eligibility. After dispatch: check the carrier options.

  3. 03Adviser reply

    Let me check the options for this delivery.

Keep the important steps in view.

Advisers can check items manually. With AI Checking enabled, Copilot uses each item’s help text to detect the behaviour in adviser turns. A checked item is not proof that a business-system update succeeded.

Bring the right script page to the adviser.

A Copilot rule can suggest a script page. The script must be the one assigned to the queue. Any data lookup or update needs its own configured script action and integration.

Where Copilot can give agents time back

For a Message Direct pilot, measure call handling time and time spent writing up each call.

60 seconds off average handle time

At Eir, Copilot brought up relevant guidance during calls and drafted notes and wrap-up suggestions afterwards.

5 minutes down to 2–3 minutes

At Keiyo Bank, transcripts, call reasons and draft summaries cut the time agents spent on after-call work.

Choose the shape of the interaction record.

AI Studio standard mode offers conciseness, format, participant labels and insights. Select a summary configuration with the same language as the Copilot, then let the adviser review the record.

  1. 01Reason

    The customer asked about an address change.

  2. 02Resolution

    Record what the conversation established.

  3. 03Action items

    Record any next steps discussed.

Use a custom prompt when the record needs more control.

Custom mode uses an authored summary prompt. Test it with varied transcripts for accuracy, instruction following and latency. A selected configuration guides generated text; it does not verify an external transaction.

  • AStandard mode

    Choose format, conciseness and insights.

  • BCustom mode

    Write and test a custom summary prompt.

Suggest a code for the adviser to review.

When prediction is enabled, Copilot can suggest up to three wrap-up codes in after-call work. Add descriptions and assign the codes to the queue. The adviser reviews and selects the code.

  1. 01Prediction

    Suggested code: Delivery enquiry

  2. 02Adviser review

    Does that code describe this conversation?

  3. 03Selection

    Apply the appropriate code assigned to the queue.

A third-party action emits an event. An integration must receive it, do the work and post the response back to Genesys Cloud for the suggestion panel. A rule alone does not create this connection.

What a voice rollout needs

Agent Copilot is available on Genesys Cloud CX 1 through AI Experience tokens.

Voice queue setup

Enable the right Copilot and language on each selected voice queue. Assign the required agent permissions.

Client content

Maintain the approved instructions, steps and wrap-up codes for the call types in scope.

Voice assistant

Treat the rental voice assistant as a separate capability. Verify the summary in the receiving agent’s view.

Extend the workflow

AI Guides can guide a configured task. A third-party action needs an integration with the Notifications API.
